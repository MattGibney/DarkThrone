# Shadcn Utils Agent Guide

## Purpose

Tailwind and utility helpers used by shadcn components.

## Architecture

- Utilities: `libs/shadcnutils/src/**`
- Tailwind config: `libs/shadcnutils/src/tailwind.config.ts`

## Local Commands

- Lint: `npx nx lint shadcnutils`

## AI Development Rules

- Keep utilities generic and reusable.
- Avoid app-specific styling decisions here.
- Maintain compatibility with shadcnui components.
