# Shadcn UI Agent Guide

## Purpose

Generated shadcn UI component library for shared UI primitives.

## Architecture

- Components: `libs/shadcnui/src/*`

## Local Commands

- Add component: `npx nx run shadcnui:add-component`

## AI Development Rules

- Prefer generator for new components to keep consistency.
- Avoid editing generated components unless necessary.
- Keep updates compatible with current Tailwind setup.
